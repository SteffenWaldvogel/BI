# Overleaf-Projekt: BI-Portfolio Thema 1.2

- Compiler **pdfLaTeX**, Hauptdatei **main.tex** (alles in einer Datei; `code/` nur für Listings)
- Layout nach Handreichung Kap. 3.4 wie PA2: Times 12 pt, Ränder 2,5/2,0/2,5/2,5 cm, 1,5-zeilig
- Keine Quellenbelege, kein Literaturverzeichnis, kein KI-Verzeichnis (Vorgabe Kirchberg)
- Aufbau des Textteils: Abbildung (Screenshot) → was gemacht wurde → Entscheidung + verworfene Alternative
- Screenshots als PNG nach `bilder/` legen; `\abb{name}{Unterschrift}{label}{Breite}` zeigt `bilder/name.png`,
  solange die Datei fehlt, einen grauen Platzhalter mit dem erwarteten Dateinamen
- `\todo{...}` = offene Stelle (rot); vor Abgabe `grep -n todo main.tex`
- Listings im Anhang zeigen Zeilenbereiche aus `code/Section1.m` – bei Änderungen an der Mappe neu extrahieren und Zeilen prüfen
- Upload: `ausarbeitung/overleaf_upload.zip` → Overleaf „New Project → Upload Project“
